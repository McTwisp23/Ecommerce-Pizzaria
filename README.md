# Pizzaria Sabor do Tempero (site estático)

## Páginas
- `index.html` — cardápio + carrinho
- `checkout.html` — dados do cliente + pagamento simples
- `pedidos.html` — histórico de pedidos (salvo no navegador)

## Publicar no GitHub Pages
1. Suba os arquivos do ZIP no repositório (raiz)
2. Settings → Pages → Deploy from a branch → Branch: main / root
3. Acesse a URL do Pages.
